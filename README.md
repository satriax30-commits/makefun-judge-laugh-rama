A tiny deterministic Node 22 program that writes one original single-line
office joke (at most 200 characters) to `/output/entry.txt`. No network, no
wall clock, stdlib only — it validates the joke (1–200 characters, one line,
not only whitespace), writes it, then reads it back and checks it matches.

Run it with:

```sh
node main.ts
```
